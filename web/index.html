Объекты пути (3D)
Меши считает track_geometry.build_track (X поперёк, Y вдоль, Z вверх). Плашки: измерено — по лидару, ГОСТ — профиль из стандарта. По умолчанию меши выключены: видна «лента рельсов» вьюера (оранжевые точки зоны rail). Включите «рельсы» — и лента гаснет, чтобы не было двух моделей сразу; выключите — вернётся как была. Вид по объектам — пресет «Объекты пути» в блоке «Камера»: галочка «автовид по объектам» снята по умолчанию — тогда при открытии ставится пресет «От лидара»; включённая галочка отдаёт стартовую камеру слою (одно перемещение, когда придёт /track). «Чистое поле»: облако скрыто, нейтральный фон, камера по габариту рельсов и шпал (пол в кадрирование не входит — он плита ~199 м); повторное нажатие возвращает облако и прежнюю камеру.
Объекты из замеров
То, что измерено в записи: обделка туннеля, основание пути, контактный рельс (видимое закрытие), его оснастка, кабельный лоток, платформа с нишами и порталом, оборудование на стенах, найденное инвентарём, плюс ходовые рельсы и пол из track_geometry. Список семейств собирается автоматически из objects/specs — вручную ничего не прописано. Плашки: измерено — замер по лидару, ГОСТ / перенесено — тело по стандарту или объект поставлен по оси с другой записи. Объект, не прошедший приёмку (числа не подкреплены точками), выключен по умолчанию, а сам блок выключен целиком: галочка «объекты из замеров» снята, 3D-объекты включаются вручную. Галочка в строке показывает/скрывает семейство. «Вписать объекты» ставит камеру по габариту ВСЕГО показанного (обделка и основание при этом занимают весь кадр), «Вписать мелкие» — по объектам размером до 6 м (кожух контактного рельса, лоток, щитки, ниши): с него удобно начинать.
